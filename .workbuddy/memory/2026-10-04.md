## 排查「指令已送达但客户端无响应」

### 现场证据
用户发 `{"name":"run_workflow","parameter":{},"other":{},"from":["server"],"to":["5a13a4fe"]}`，
网页端提示已连接，客户端零响应。

逐步排查：
1. `GET /api/clients` 确认 `5a13a4fe` **在线**（当时叫 `ComfyUI-3738`，sender）
2. 翻服务端日志 → `指令「run_workflow」已转发给 1 个客户端：['ComfyUI-3738']`
   **服务端这一段是通的，指令确实投递出去了**
3. 查该客户端 UA → `Mozilla/5.0 (Windows NT 10.0...) Chrome`
   → **不是 ComfyUI 节点（无头 UA），是浏览器里的页面**（油猴脚本之类）
4. 结论：客户端连了、也收到了，但**没实现指令处理，也没回 command_result**，
   所以网页端看起来「石沉大海」。

### 改进（让下次排查不用猜）
- `command_result` 区分两种：`awaiting_ack:true` = 只是「已送达」，
  没有该字段 = 客户端**真的回执了**。前端日志也据此分色：
  投递提示标 `out`（灰青）+ "等待回执…"，真回执标 `exec`（紫）。
- 服务端维护 `_pending_cmds`，日志会打 `↳ 等待客户端回执` / `✓ 客户端已回执「x」：detail`。
- 新增内置指令 `whoami`：客户端回它就能确认通道是否连通、回执带 id/名字。
- 新增 `tools/probe_command.py`：直接探测某个客户端「收没收到 / 回没回执」。

### 探针自身的 bug（写测试时踩到）
`recv(ws, want)` 原来只收一条、不匹配就丢弃 —— 但连接上**先来的是 `clients` 广播**，
于是把真正的 `command_result` 读漏了，误报「服务端没回执」。
**教训：WebSocket 收消息必须循环跳过不匹配的，而不是读一条就返回。**
修法：`recv` 加 pred 参数，循环直到 type 匹配且满足条件。

### 验证
前端桩补「投递提示 vs 客户端回执」等 4 项，前端扩到 105 项；五套共 236 项全通过。

## 修油猴脚本（ComfyUI-JS-Bridge.user.js）收不到指令

### 用户的客户端是什么
`example/ComfyUI-JS-Bridge.user.js` —— 油猴脚本，跑在 RunningHub / LiblibArt 的
ComfyUI 页面里。UA 是 Chrome（所以之前从 UA 判断「不是 ComfyUI 节点」是对的）。

### 三个叠加的根因
1. **to 双重过滤 → 静默丢弃（致命）**
   服务端登记 id 是自己生成的（`5a13a4fe`），脚本又按自己 localStorage 的
   `clientId`（`c...`）过滤一次，**两边永远对不上** → 收到就跳过。
   修法：服务端支持 `?clientId=` 自报 id 并沿用；脚本的 to 命中判断改为
   「自报 id **或** 服务端 id 任一命中」，且从 `welcome.client_id` 取服务端 id。
2. **完全没有回执**
   `dispatchCommand` 只在面板打日志，从不发 `command_result` →
   网页端永远停在「等待回执…」，用户看不到任何反馈。
   修法：新增 `makeReplyer(sock)`，6 条分支全部回执（含失败原因）。
3. **指令名与空 parameter**
   网页端发 `run_current_workflow`，脚本只认 `run_generate` → 已加别名。
   `parameter:{}` 时原来直接抛错 → 改为**退回执行当前画布工作流**。

### 教训：aiohttp send_str 必须 await
写模拟客户端时 `self.ws.send_str(...)` 漏了 await，只报
`RuntimeWarning: coroutine ... was never awaited`，
**回执静默丢失**，排查时极具误导性（一切看起来都对，就是不回执）。
同步 `handle()` 也要改成 `async def` + `await self.handle(...)`。

### 验证
新增 `tools/verify_bridge_client.py`（18 项），复刻脚本的连接/过滤/回执行为。
六套共 254 项全通过。
